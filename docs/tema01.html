1. ¿Qué es una red informática y para qué sirve?

Una red informática es un conjunto de dispositivos (ordenadores, móviles, impresoras, servidores...) conectados entre sí, mediante cables o de forma inalámbrica, que siguen unas reglas comunes llamadas protocolos para poder intercambiar información y compartir recursos.

Piensa en una red como en la red de carreteras de una ciudad: las carreteras no sirven de nada por sí solas, sirven porque permiten que las personas y las mercancías se muevan de un sitio a otro siguiendo unas normas de circulación compartidas. Una red informática es igual: los cables y las antenas no importan por sí mismos, importan porque permiten que la información viaje de un dispositivo a otro siguiendo un protocolo común.

Concepto clave Las redes existen, fundamentalmente, para compartir: documentos, impresoras, acceso a Internet o información centralizada en un servidor. Los cables y los protocolos son solo el mecanismo que lo hace posible.

¿Para qué usamos las redes?

Aunque cada red tiene su propósito, casi todas existen por alguna de estas razones:

MotivoEjemplo cotidiano
ComunicaciónEnviar un mensaje de WhatsApp, hacer una videollamada, mandar un correo
Compartir recursosVarios ordenadores de una oficina usan la misma impresora en red
Compartir informaciónGuardar un documento en una carpeta compartida para que lo vea todo el equipo
Centralizar serviciosTodos los alumnos del instituto acceden al mismo Moodle desde un único servidor
Ahorrar costesCompartir una única conexión a Internet entre todos los dispositivos de una casa
Colaborar en tiempo realVarias personas editando el mismo documento de Google Docs a la vez
🤔 Para pensar: Internet es, en realidad, "la red de redes": millones de redes más pequeñas (la de tu casa, la de tu instituto, la de una empresa...) conectadas entre sí. Cuando visitas una página web, tu petición puede pasar por decenas de redes distintas antes de llegar al servidor que la aloja.

2. Hardware de conexión, electrónica de red y software: tres piezas, no dos

Es habitual simplificar y decir que una red tiene "hardware" y "software", pero para entender bien cómo funciona conviene distinguir tres familias de elementos, no dos:

1. Hardware de conexión

Lo que emite y recibe la señal en cada dispositivo final: adaptadores de red, cables, antenas.

2. Electrónica de red

Los dispositivos intermedios que organizan y dirigen el tráfico: switches, routers, puntos de acceso, módems.

3. Software de red

El sistema operativo, la pila de protocolos y los servicios que deciden qué se envía y cómo se interpreta.

💡 Esta distinción evita un error muy común: pensar que un switch o un router son "solo hardware". En realidad son electrónica de red: hardware especializado que además ejecuta su propio software interno para decidir por dónde envía cada dato.

3. Estaciones de trabajo y adaptadores de red

Se llama estación de trabajo a cualquier dispositivo final que usa la red: tu PC del aula, un portátil, una tablet, un móvil o incluso una impresora de red. Son los dispositivos que "quieren conectarse", a diferencia de la electrónica de red, que existe para que esa conexión sea posible.

Para que una estación de trabajo pueda conectarse a una red necesita un adaptador de red (también llamado tarjeta de red o NIC, del inglés Network Interface Card): el hardware de conexión del que hablábamos en el apartado anterior. Hoy en día casi todos los ordenadores llevan dos adaptadores integrados:

  • Adaptador Ethernet (cableado): tiene un puerto RJ-45 donde se conecta un cable de red.
  • Adaptador Wi-Fi (inalámbrico): se conecta a una red sin cables, mediante ondas de radio.

Cada adaptador usa una dirección MAC de 48 bits (por ejemplo, 3C:E1:A1:4F:9B:02) para identificarse en la red local. Muchas interfaces traen una dirección asignada por el fabricante, pero el sistema también puede utilizar una dirección administrada localmente o aleatoria. Volveremos sobre ella en el Tema 5.

4. Servidores y clientes: el modelo cliente-servidor

En muchas redes, el papel de cada equipo no es simétrico: unos ofrecen un servicio de forma permanente y otros lo solicitan cuando lo necesitan. A esto se le llama modelo cliente-servidor:

  • El servidor es un equipo (normalmente potente y siempre encendido) que ofrece un servicio: almacenar páginas web, guardar archivos, gestionar el correo, imprimir documentos, asignar direcciones o traducir nombres de dominio.
  • El cliente es el dispositivo que solicita ese servicio: tu navegador pidiendo una página web, tu ordenador enviando un documento a la impresora de red, tu móvil descargando el correo.

Como el servidor tiene que estar disponible en todo momento, su caída se nota en toda la red a la vez: si el servidor de Moodle del instituto se apaga, ningún alumno puede entrar, aunque su propio ordenador funcione perfectamente.

5. Electrónica de red: switches, routers, bridges y puntos de acceso

Además de las estaciones de trabajo y los servidores, toda red necesita electrónica de red cuyo único trabajo es interconectar a los demás. Son los "encargados de tráfico" de la red.

5.1. Switch (conmutador)

Un switch conecta varios dispositivos dentro de una misma red local (por ejemplo, todos los ordenadores de un aula). Cuando un dispositivo envía datos, el switch aprende automáticamente en qué puerto está conectado cada dispositivo (identificándolo por su dirección MAC) y envía la información solo al puerto correcto, en lugar de reenviarla a todos los puertos.

5.2. Router (encaminador)

Un router conecta redes distintas entre sí. El ejemplo que todos tenéis en casa: el router conecta vuestra red doméstica con la red de vuestro proveedor de Internet, y decide el mejor camino para que los datos lleguen a su destino. Sin router, tu red local podría funcionar internamente (los dispositivos se verían entre sí), pero no tendría salida al exterior.

Muchos routers domésticos son en realidad varios dispositivos en uno: router + switch + punto de acceso Wi-Fi, todo en la misma caja. Por eso a veces cuesta distinguir dónde acaba uno y empieza otro.

Concepto clave Switch = conecta dentro de una misma red. Router = conecta redes distintas entre sí. Es la distinción más importante de todo el tema: casi todo lo demás se entiende a partir de aquí.

5.3. Bridge (puente)

Un bridge es, históricamente, el antecesor del switch: une dos segmentos de una misma red para que funcionen como si fueran uno solo, filtrando qué tráfico pasa de un lado a otro. Hoy en día los bridges dedicados casi han desaparecido (su función la hace un switch), pero el concepto sigue siendo importante: cuando dos redes Wi-Fi se combinan en una sola o cuando se conecta un segmento de fibra con uno de cobre, se está haciendo de "puente" entre ambos.

5.4. Punto de acceso (Access Point)

Un punto de acceso permite que los dispositivos se conecten a una red mediante Wi-Fi, sin cables. No decide caminos como un router ni aprende direcciones MAC como un switch: simplemente "traduce" entre el mundo inalámbrico y el mundo cableado. En un instituto o una oficina grande, es habitual tener varios puntos de acceso repartidos para cubrir todo el edificio con la misma red Wi-Fi — y cada uno de ellos sigue necesitando un cable hasta el switch más cercano: lo único "inalámbrico" es el último tramo, entre el punto de acceso y tu dispositivo.

7. Evolución histórica de las redes: de ARPANET a hoy

Antes de las redes: la era del mainframe

Antes de 1969, "usar un ordenador" normalmente significaba sentarse frente a un terminal sin capacidad propia de proceso, conectado a un único ordenador central (mainframe) que repartía su tiempo entre todos los usuarios por turnos. Si ese ordenador central fallaba, todo el mundo se quedaba sin servicio a la vez: no había ninguna alternativa. Entender esto ayuda a valorar lo revolucionario que fue lo que vino después.

1969 — ARPANET

La agencia de investigación militar estadounidense ARPA pone en marcha ARPANET, la primera red de conmutación de paquetes a gran escala, conectando cuatro nodos: UCLA, el Instituto de Investigación de Stanford (SRI), la Universidad de California en Santa Bárbara y la Universidad de Utah. El 29 de octubre de 1969 se transmite el primer mensaje entre dos de estos nodos: un intento de escribir "LOGIN" que se cae justo después de la "O", así que, sin querer, el primer mensaje de la historia de Internet fue "LO".

Conmutación de paquetes vs. conmutación de circuitos

La gran novedad técnica de ARPANET fue dividir la información en paquetes independientes que viajan por caminos distintos y se reordenan al llegar, en vez de reservar una línea fija de extremo a extremo (como hacía el teléfono tradicional). Esto hace que la red sea mucho más resistente: si un camino falla, los paquetes simplemente toman otro.

1971 — Primer correo electrónico

Ray Tomlinson envía el primer mensaje de correo electrónico entre dos ordenadores de ARPANET, y populariza el símbolo @ para separar el nombre de usuario del nombre del ordenador (hoy, del dominio).

1976-1977 — Primeras redes internacionales

El enlace SATNET, vía satélite, conecta ARPANET con redes de Europa, dando los primeros pasos hacia lo que más tarde sería una red verdaderamente mundial.

1 de enero de 1983 — "Flag Day": nace Internet

Todos los ordenadores de ARPANET cambian de forma coordinada al protocolo TCP/IP, el conjunto de reglas de comunicación que seguimos usando hoy. Esta fecha se considera, simbólicamente, el nacimiento de Internet tal y como lo entendemos: una red de redes que habla un idioma común.

1973 en adelante — Ethernet

Robert Metcalfe inventa Ethernet en el centro de investigación Xerox PARC. Se convierte en el estándar dominante para redes locales cableadas, y lo sigue siendo hoy, décadas después (aunque mucho más rápido: de unos pocos Mbps en sus inicios a varios Gbps actualmente).

1997-2019 — Wi-Fi: de 2 Mbit/s a casi 10 Gbit/s

Se publica el estándar 802.11 (lo que hoy llamamos Wi-Fi) y se generaliza rápidamente en hogares, oficinas y centros educativos.

IPv6: la respuesta a un problema de números

El sistema de direcciones "de toda la vida" (IPv4) usa números de 32 bits: unos 4.300 millones de direcciones distintas. En 2011 se declaró oficialmente agotado el bloque principal de direcciones IPv4 disponibles. IPv6 usa números de 128 bits, multiplicando la cantidad de direcciones posibles hasta más de 340 sextillones. Hoy convivimos con ambos sistemas a la vez (lo que se llama "doble pila"): IPv6 ya transporta una parte muy importante del tráfico de Internet.

Glosario del tema

Red informática

Protocolo
Conjunto de reglas que permite que los dispositivos de una red se entiendan entre sí.
Hardware de conexión
Componentes que emiten y reciben la señal en un dispositivo final: adaptadores de red, cables, antenas.
Electrónica de red
Dispositivos intermedios que organizan y dirigen el tráfico: switches, routers, puntos de acceso, módems.
Adaptador de red (NIC)
Componente que permite a un dispositivo conectarse a una red, por cable o por Wi-Fi.
Dirección MAC
Identificador de 48 bits usado por una interfaz dentro del enlace local; puede ser de fábrica o administrado localmente.
Cliente-servidor
Modelo en el que un equipo (servidor) ofrece un servicio de forma permanente y otro (cliente) lo solicita.
Switch
Dispositivo que conecta varios equipos dentro de la misma red local.
Router
Dispositivo que conecta redes distintas entre sí y decide el camino de los datos.
Bridge
Dispositivo (hoy en desuso) que une dos segmentos de una misma red.
Punto de acceso
Dispositivo que permite conectarse a una red mediante Wi-Fi.
Conmutación de paquetes
Método de transmisión que divide la información en paquetes independientes que pueden viajar por caminos distintos.
ARPANET
Primera red de conmutación de paquetes a gran escala (1969), origen de Internet.
TCP/IP
Conjunto de protocolos que rige la comunicación en Internet desde 1983.
Ethernet
Estándar dominante de redes locales cableadas, inventado en 1973.
Wi-Fi (802.11)
Estándar de redes inalámbricas locales, publicado en 1997 y mejorado en velocidad desde entonces.
WEP / WPA / WPA2 / WPA3
Sucesivos estándares de seguridad para proteger redes Wi-Fi; WPA3 es el recomendado hoy.
IPv6
Sistema de direcciones de red de 128 bits, diseñado para no agotar las direcciones disponibles.

Resumen esencial

  1. Las redes conectan dispositivos para compartir datos y recursos, siguiendo protocolos comunes.
  2. Distingue tres piezas: hardware de conexión (adaptadores, cables), electrónica de red (switches, routers, puntos de acceso) y software de red.
  3. En el modelo cliente-servidor, el servidor ofrece el servicio de forma permanente y el cliente lo solicita cuando lo necesita.
  4. Switch conecta dentro de una misma red; router conecta redes distintas. Es la distinción más importante del tema.
  5. Bridge une segmentos de una misma red; punto de acceso da entrada Wi-Fi a la red cableada.
  6. Internet nació de ARPANET (1969, conmutación de paquetes) y se consolidó con TCP/IP (1983).
  7. Ethernet (cable) y Wi-Fi (802.11) dominan hoy las redes locales; WPA3 e IPv6 son las versiones actuales de seguridad y direccionamiento.
